Andal (Analisis Dangkal) membuat video pendek "Kenapa?" berbahasa Indonesia: pertanyaan sehari-hari dijawab singkat dengan animasi 2D dan riset bersumber.

Andal (Analisis Dangkal) makes short Indonesian-language "Why?" videos: everyday questions answered briefly with 2D animation and sourced research.

Di mana / Where

  • YouTube: @analisisdangkal

Alat internal / Internal tool

Video kami diproduksi dan diunggah dengan alat internal, andal-pipeline, yang hanya dipakai oleh pengelola channel ini untuk akun milik channel sendiri. Alat ini memakai YouTube Data API, Instagram Graph API, dan TikTok Content Posting API untuk mengunggah dan menjadwalkan video kami, serta Google Sheets API untuk mencatat daftar video kami.

Our videos are produced and uploaded with an internal tool, andal-pipeline, used only by this channel's operator for the channel's own accounts. It uses the YouTube Data API, Instagram Graph API and TikTok Content Posting API to upload and schedule our videos, and the Google Sheets API to keep a log of our videos.
